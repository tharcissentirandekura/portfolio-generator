Computer Architecture connected the code I write to the machine that executes it.

- Hardware constraints influence software performance.
- Representation is part of computation.
- Memory hierarchy explains behavior source code cannot.

# My experience

The course gave me a clearer mental model for the layers between a high-level language and hardware. Instructions, registers, caches, and memory stopped being separate vocabulary and became parts of one execution path.

# What stayed with me

Performance is not magic hidden beneath the application. It emerges from concrete decisions about data movement, locality, and the work a processor must perform.

## Advice for someone taking it

1. Trace instructions slowly before trying to move quickly.
2. Keep a compact reference for representations and instruction formats.
3. Connect each new hardware idea back to a familiar program.
